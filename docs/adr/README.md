# Decisiones de arquitectura (ADR)

Un archivo por decisión que costó pensar y que sería caro revertir. Registra el
contexto y lo descartado, no solo el resultado: dentro de un año lo que hace falta
saber es *por qué no* se hizo de la otra forma.

Numeración correlativa. Una decisión no se edita: se supera con una nueva que la
marque como reemplazada.
